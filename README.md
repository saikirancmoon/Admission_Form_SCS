# Sri Chaitanya School – Home2

This project serves the Home2 school site. The root route redirects to `/home2`.

## Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000); it redirects to [http://localhost:3000/home2](http://localhost:3000/home2).

## Production check

```bash
npm run build
npm start
```
